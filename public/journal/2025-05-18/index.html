Youtube as atproto PDS?

atproto's main idea is to have data that can live forever (by allowing users to customize the PDS). Doesn't this mean, I can have my training data of youtube? What if:

  • Like bluesky posts, user's youtube watching activity will be posted in atproto.

  • They can move that data to bring their preference to other YT services.

  • Even futher, when user uploads a video, that will be posted on atproto (targetting to youtube, but configurable, like PDS)

  • Wait, did I just created a youtube feed..?

So in summary, isn't it theoretically possible to use YouTube itself as a PDS. User can use other video PDS like odysee if they don't trust YT.

No, not replacing the youtube, but we can at least use other atproto-based applications as an entry point. Like blogs.

Currently bluesky has hard 300 character limit for it's post. So only way for users running their blog over atproto is to include bluesky-compatible fields like links to their blog post.

We can do similar. We won't provide youtube client but we can create an entry point to youtube.

YouTube Repost
