dream keyboard

designed an ortholeaner keyboard layout: https://www.keyboard-layout-editor.com/#/gists/9e6fc99bf0ba58eec19de9391ee4b530

but after using a LP corne I setup before (with home-row mod and miryoku-like layout) for a while, I found that I'm actually liking the column-stagger layout more than I thought. Because of my finger lengths, I think I should lower the index/pinky columns quite a bit if I go with column-stagger layout. (I think keyball39 layout seems quite appealing)
