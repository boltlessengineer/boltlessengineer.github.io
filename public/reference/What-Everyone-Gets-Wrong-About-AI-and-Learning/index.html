What Everyone Gets Wrong About AI and Learning

link: https://youtu.be/0xS68sl2D70?si=XXQgc5wGz5rVd3O2

Our brain has two system

  • system 1. that thinks based on memory fast without actual thinking

  • system 2. that actually reasons something but is very, very lazy.

system 2 is so lazy that it usually just ends up with "hey system 1, what's the answer, ...yeah that sounds right, I'll take that".

We need to learn when we should use system 1 and when we should activate system 2.

Experts become an expert by their massive amount of long term memories.

As an evidence, chess master cannot remember chess board with items radomly placed.

So really what we want to be doing in education is using System 2's resources very carefully and repeatedly, such that we store information in long term memory to allow our System one to do things that effectively feel automatic.

Riiiiight. This really makes sense.
