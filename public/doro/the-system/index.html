Keywords

Instead of obsidian style [[wikilink]], use [keyword] style syntax. When I refer something, use [something] and connect the link later. There can be a tool to suggest me some possible targets (:$/doro/something, :$/reference/something)

Syntax

Similar to alias field in obisidan, have optional synonyms field. synonyms is specifies which keywords current note can be referred to by. This is not a strict value that is used from linkables, but a semantic helper to auto-complete long link targets.
