html template language

2026-01-11

I want ultimate html template language that doesn't feel like raw string template.

I want structured language, but don't want complete new language without familiar html syntax.

maybe something like lisp? should I use janet?

lit is for CSR, but seems pretty clean: https://lit.dev/articles/lit-cheat-sheet/

Maybe something like context provider? e.g. when value like "current user session" is used everywhere, it makes sense to use context provider instead of passing it to deeply nested component. Imagine "newComment" component. It needs session context, and passing value that deep is pretty hard.

problems

  • programatically generate a page from template on runtime (e.g. profile page with specific tab opened)

  • components that feels like JSX

  • consistent syntax

  • dynamic attributes / attribute values
