Debugging my productivity

Debugging my productivity

2025-04-29

DAMN my productivity really goes down when I'm home. Let me take an excuse.

  • I'm on short vacation. Which means I can only start thing that I can finish in less than 4 days.

  • My sleep routine is completely broken. Which leads to forgetting daily habits like journalling.

  • I'm facing a problem but I cannot found a satisfying way to solve it.

2025-04-30

I found that I become instantly productive when I'm back to military service.

  • I turned off all YT videos/streams

  • On oracle server, I can get syntax highlighting for my norg documents (I don't have syntax highlighting in my mac yet)

  • I'm using iPad, where I locked both brave browser and dcinside.

I also felt pretty productive when I watch YT videos with iPad in cafe just before returning to military.
