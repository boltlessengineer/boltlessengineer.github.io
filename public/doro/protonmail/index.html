Things that can be fixed

  • Swipe gesture is working by percentage and not by fixed length. This makes swiping in iPadOS pretty weird.

  • Some emails on dark mode are broken due to white text color with white background. (e.g. search for title "Apple 계정 정보가 업데이트되었습니다.")

  • Sidebar menu's gesture and animation are not smooth

  • iPadOS shortcuts

    • cmd+enter to send email

Features I'd like to see

  • Content server that can be hosted locally to search emails with its actual contents

  • Opt-out security features that leads to slow loading speed (e.g. DOM purify)

  • Put folders into bottom bar for easy access (like hey)
