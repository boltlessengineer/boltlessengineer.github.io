llm to create db queries

2025-05-24

Use LLM as an interface which user can use to create complex database queries or filters.

Possible Use-cases

  • Notion or Obsidian can use this to create a table view instead of creating DSL like Excel

  • Bluesky or atproto can use this to create custom feed without even knowing the available query options
