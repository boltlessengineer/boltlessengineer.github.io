tangled.sh

2025-05-25

tangled.sh is a git collaboration platform built on top of /doro/atproto.

It's quite new, as of today (2025-05-25) it doesn't even support private repositories. But general idea seems pretty promising.

It also supports stacked PR with jj-vcs in mind.

Draft PRs

Issue/PR/Comment Edits

If someone edits one of these in collaboration platform, we usually expect some kind of edit history.

But I'm not sure if atproto allows it.
