CommonNorg Guide

TLDR; What has been changed?

Block level

  • Slide and indent segment are removed and replaced with null indent.

  • Renamed extensions to attributes

  • Todos are not part of syntax. They should be implemented with attributes from Neorg-like applications.

  • Heading is renamed to Section. Heading now refers to Heading title from norg spec v1.

  • Removed the category "detached modifiers"

  • Removed standard ranged tags

  • Removed macro tags

  • Removed intersecting modifiers

  • Removed footnotes & definitions (reimplemented with tags)

  • Removed tables, but it isn't reimplemented yet.

  • Removed attributes (that nestable detached modifier starting with % prefix)

  • Removed weak carryover tags

Inline level

  • Removed free-form attached modifiers

  • Removed spoiler, superscript, subscript, inline math, null modifier and variable. All of them are reimplemented with inline tags

  • : right after or before attached modifier will be treated as link-modifier no matter if it is sandwiched or not.

  • Strikethrough now uses a ~ character instead of - (this is not just a stylistic choice)

Link Target Syntax

Completely refactored so it is easier to re-explain from ground up, but here is a list of deprecated syntax:

  • Line Number : should be implemented from Neorg-like applications

  • Timestamps : should be implemented with inline tag

  • File Linkable ({/ this}) : merged with uri-link

  • Extendable link : should be implemented with inline tag

  • Inline linkable : should be implemented with inline tag & attribute

Macro system

  • Replaced with combination of tags and macros.

  • tags expand to list of abstract objects.

  • macros expand to list of blocks

Misc

  • Re-arranged layers to three

  • Redesigned attributes (previously extensions) syntax
