Indents

In CommonNorg, you can indent base blocks like headings, tags or paragraphs. Indents in CommonNorg have a level and a type. Instead using arbirtrary amount of spaces or tabs, in CommonNorg, you indent a block with special prefix characters representing the indent type.

There are four different types of indents:

  • - : unordered list item

  • ~ : ordered list item

  • > : quote item

  • / : continue item

Nestable Detached Modifiers

  • Consecutive indented blocks with same indent level & indent type will form a list.

  • List with higher level can be nested as sublist.

  • A / type list with same indent level can be used to span the list item content to multiple blocks

You can think nestable detached modifiers work just like indent based markup languages (like markdown or orgmode), but it uses explicit repeated prefix instead of whitespace indents.
