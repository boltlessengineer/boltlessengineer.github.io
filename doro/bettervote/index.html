Problems

어떻게 해야 중립적인 기사를 전달할 수 있지?

어떤 기사를, 어떤 정보를 가져오더라도 그건 단편적이고 편향된 정보일 수 있음. 사실 여부와 관계 없이 자료의 표시 방법을 바꾸는 것 만으로도 전혀 다른 의미가 됨.

Solution

기사 인용 시스템. 댓글이 기사를 정정하기보단 해당 주제에 관한 또다른 기사를 인용해서 다른 시선을 공유하게 만들 수 있음.

같은 주제를 다루고 있는지는 AI로 판별이 가능...하지 않을까 싶음
