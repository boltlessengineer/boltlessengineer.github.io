the dream keyboard layout

I'm testing the layout in my LP corne v1. It's already pretty convenient at this moment.

I still have to test in multiple situations, but basic web browsing and writing is pretty fine. I might need to adjust the tap-hold-term later.

  • I'm enjoying 한영키 implemented as combo of K and L.

  • I'm enjoying - and ` keys right next to my left pointing finger.

  • I found that I don't necessarily need to put shift key in home-row-mod. Home row mods can be easily annoying, and current shift key position isn't that bad.

  • I miss the backspace in thumb key.

  • ,./ below the layer is pretty annoying. I'd rather prefer to have them in base layer. but then I can't put trackball in right side of the keyboard. Hmmmm... Maybe I should just try the mouse key layer like gangjun06 suggested.

  • I need a gui at thumb cluster anyways because I have to type CMD-C, CMD-V in one hand when I'm using a mouse.

  • I might disable a shift key in home-row entirely to avoid any miss-typing and make strong muscle memory of using shift key with my pinky fingers all time.
